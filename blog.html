یادداشت‌های فنی · Technical Notes

یادداشت‌هایی درباره Front-End، Angular، استقرار، SQL Server و تجربه حل مسئله در پروژه‌های واقعی.

Angular · Front-End

ساخت Front-End قابل نگهداری

ساختار پوشه روشن، componentهای کوچک با مسئولیت مشخص، نام‌گذاری یکدست، مدیریت state قابل پیش‌بینی و توجه به accessibility پایه یک Front-End قابل توسعه هستند.

در پروژه‌های واقعی، سادگی معماری معمولاً از پیچیدگی زودهنگام ارزشمندتر است. هدف این است که توسعه‌دهنده بعدی بتواند سریع مسیر داده و رفتار UI را درک کند.

IIS · SQL Server · Support

از توسعه تا استقرار واقعی

یک محصول فقط زمانی کامل است که در محیط واقعی قابل اتکا باشد. بررسی تنظیمات IIS، connection string، مجوزها، لاگ‌ها و تفاوت نسخه‌های محیط از بخش‌های مهم عیب‌یابی هستند.

ثبت دقیق خطا و بازتولید مسئله قبل از تغییر سیستم، زمان رسیدن به علت اصلی را کوتاه‌تر می‌کند.
