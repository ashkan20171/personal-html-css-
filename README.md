# AshkanX Personal Portfolio v3
Personal portfolio of **Ashkan Motaei / اشکان مطاعی** built with pure HTML, CSS and JavaScript.

## v3 highlights
- Fully bilingual FA/EN header and content with RTL/LTR switching
- Advanced 3D hero, tilt effects, animated background and custom cursor
- Preloader, scroll progress and back-to-top
- Project filtering, project modal and 4 dedicated project case-study pages
- Certificates section
- Interactive resume with Front-End / Support / Toolbox modes
- Services and work-principles/testimonials-style section
- GitHub activity/profile panel
- Technical blog + standalone blog page
- Command Palette (`Ctrl/Cmd + K`) for navigation/actions
- Dark/light theme with persistence
- Ashkan AI on-site assistant (local knowledge-base; no exposed API key)
- Responsive, keyboard friendly and reduced-motion aware
- SEO metadata, JSON-LD, sitemap, robots and PWA manifest

Open `index.html` directly or serve the folder with any static server.
